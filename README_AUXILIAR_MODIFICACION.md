# Auxiliar local de MODIFICACION

El auxiliar permite que la aplicación web solicite la lectura de la ventana `MODIFICACION` de Internet Explorer.

## Instalación en cada computador cliente

1. En la aplicación, pulse `Descargar auxiliar MODIFICACION`.
2. Descomprima `auxiliar_modificacion.zip` en una carpeta.
3. Ejecute `instalar_auxiliar_modificacion.bat`.
4. Acepte la confirmación de Windows si aparece.

La instalación registra el protocolo local `liquidacion://` para el usuario actual. No requiere permisos de administrador.

## Uso

1. Abra en IE la ventana `MODIFICACION`.
2. En la aplicación web pulse `Obtener datos MODIFICACION`.
3. Si el navegador pregunta si desea abrir una aplicación externa, permita `Liquidación Web`.
4. Cuando aparezca la confirmación, vuelva a la aplicación y pulse `Pegar datos SITFA`.

El botón `Descargar .BAT MODIFICACION` continúa disponible como alternativa manual.
